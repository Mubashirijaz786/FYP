# Market on Wheels

## Project Overview

**Market on Wheels** is a multi-vendor marketplace website and mobile application that allows users to order products from multiple nearby vendors, including grocery stores, pharmacies, dairy shops, and restaurants, through a single delivery.

The platform will use AI-based recommendations and route optimization to suggest nearby vendors based on the user's location, assist with order placement, and provide optimized delivery routes for riders to reduce delivery time and travel costs.
